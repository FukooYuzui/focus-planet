# 专注花园浏览器扩展

该扩展配合 Windows 桌面应用使用，支持 Chromium 120 及以上版本的 Microsoft Edge / Google Chrome。无需账号，不上传浏览记录。

## 安装与配对

1. 保持本文件夹中的文件完整。Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
2. 打开「开发人员模式」，选择「加载解压缩的扩展」，选中包含 `manifest.json` 的本文件夹。
3. 在桌面应用的「使用限制」中设置网站，例如 `bilibili.com`，并复制配对码。
4. 点击浏览器工具栏中的扩展图标，粘贴配对码，点击「保存并连接」。显示「已连接」说明配对成功。
5. 在桌面开始专注后，点击扩展的「立即同步」可立即确认当前网站列表。默认同步通常约 5 秒，浏览器后台运行状态可能使其延迟。

如果显示「未连接」，先检查桌面应用是否运行，以及配对码是否相同。配对码保存在该浏览器配置文件的本地扩展存储中。切换桌面测试数据目录可能需要重新配对。

## 限制边界和紧急解除

- 限制目标域名及其子域的新页面导航。例如 `example.com` 会覆盖 `www.example.com`，不会覆盖 `notexample.com` 或 `example.com.evil.test`。
- 仅限制主页面请求，不读取网页内容。已经加载的网页、单页应用中的部分站内操作、离线缓存、其他浏览器、其他浏览器配置文件和未启用扩展的隐私窗口可能继续使用。
- 被阻止时浏览器会显示其自己的「已阻止」错误页面。专注结束后刷新即可重新访问。
- 只有桌面应用报告正在专注且租约有效时才添加规则。结束、紧急退出、连接失败、配对失败或收到过期状态时会清空规则。桌面租约在扩展中最多接受未来 45 秒。
- 扩展使用 `sessionRules`，完整退出并重新启动浏览器后规则不会保留。每次后台工作进程重新启动也会先清空旧规则，再重新向桌面确认状态。
- `sessionRules` 自身不支持硬性自动过期。扩展尝试每 5 秒同步，以 30 秒浏览器 alarm 唤醒兜底；浏览器完全挂起或系统休眠时无法承诺固定解除时限。恢复运行后重新确认并解除无效限制。
- 紧急时点击扩展中的「解除限制并取消配对」，或在扩展管理页面禁用本扩展。此操作会让后续专注也不再启用网站限制，直到重新配对。
- 本扩展属于自律辅助，用户仍然可以禁用、删除扩展或使用其他浏览器。

## 本地接口与权限

扩展只请求 `http://127.0.0.1:17839/state`，通过 `X-Focus-Token` 请求头提供桌面配对码。接口为只读；扩展不能启动、结束或改写桌面专注记录。响应格式：

```json
{
  "active": true,
  "domains": ["example.com"],
  "leaseExpiresAt": "2026-10-27T08:00:20Z",
  "sessionEndsAt": "2026-10-27T08:25:00Z"
}
```

`active: false` 时无需有效的时间字段。活动状态必须有合法的域名列表和两个未来时间。域名不接受 URL、路径、通配符、IP 地址或 localhost。

权限用途：`storage` 保存配对信息与状态，`alarms` 唤醒状态同步，`declarativeNetRequest` 阻止指定域名的新页面访问；主机访问权限只用于上述回环地址。浏览器可能对请求阻止权限显示网站相关警告，这是浏览器授予该能力时的提示。

## 开发验证

在本目录运行 `node --test tests/*.test.js`。测试以模拟 Chrome API 验证域名边界、租约和会话截止、断联/401、旧请求竞争、取消配对和规则失败处理。它们不等同于真实 Edge/Chrome 安装验收；真实浏览器还需检查扩展加载、桌面配对、新页面阻止、退出解除和重启恢复。

本次另在独立临时配置文件中的 Edge 156.0.4314.42 进行真实浏览器验证：扩展加载与配对、开始前可访问、目标域及子域阻止、相似后缀不误伤、结束后恢复、取消配对恢复均通过。接口由本地模拟桌面提供，临时扩展副本仅替换回环端口以避开正在运行的桌面程序；这不是与实际桌面程序的完整联调。证据保存在 `test-results/browser-smoke.json` 与 `test-results/extension-popup.png`。未更改用户现有浏览器配置，也未在其中安装扩展。

可选复现脚本为 `tests/browser-smoke.mjs`，需要 Playwright；通过环境变量 `PLAYWRIGHT_MODULE` 指定其模块位置，或在本目录可解析的环境中安装 Playwright。`EDGE_EXECUTABLE` 可覆盖默认 Edge 路径。脚本会创建并清理独立测试配置文件，不操作日常浏览器。
