# 专注星球 MVP 0.6.1 技术方案

## 更新与专注记录不变约束

正常路径由 `FocusDataProtection.DefaultDataDirectory` 固定为 `%LOCALAPPDATA%\FocusGarden`。在构造任何存储与执行中断恢复之前，App 获取实例锁和物理数据目录锁，再按程序集版本执行 `PrepareForVersion`。Windows 路径身份使用目录句柄解析，避免 junction 等目录别名产生两个互斥名；测试/验收要求独立的显式目录，并拒绝默认目录及其别名。

源库只读事务固定一致快照，`BackupDatabase` 纳入 WAL 中已提交数据；临时备份执行完整性检查与专注表逐行指纹比对，转为 DELETE 日志模式、关闭并独立重开复查。成功后原子改名并更新版本标记；任何一步失败都不会进入原库的初始化/恢复流程。此备份覆盖 `focus.db` 内的专注、按日记录、设置和应用时长，不是所有星球/Token 数据的整套备份。

FocusStore 在修改日志设置前检查 schema 版本，拒绝不支持的较新版本。新表创建及版本写入在同一事务内，已有 v1 不改版本；中断恢复仅修改状态和结束时间，不改变已保存秒数，不补算离线时间。每次发布以旧版原始 schema fixture 检查逐条会话/逐日秒数、跨日跨年、反复升级、WAL、失败保留与独立备份。

专注星球将实际专注时间与本机 Codex Token 用量转换为小星球的成长。开局是荒凉星球，随后出现植被、生物与可布置的建筑；每颗星球满六个自然月后可开拓下一颗，已有家园继续保留。0.3 的番茄钟、背景图片、当前时间、年度专注热力图、应用时长、Token 立体日历、统计导出和使用限制继续可用。

## 技术与兼容性

目标平台为 Windows x64，采用 C#、.NET 8 WPF、SQLite 和 Edge/Chrome Manifest V3 扩展。便携包主程序为 `专注星球.exe`，源码命名空间和项目名称仍使用 `FocusGarden`，以延续工程和数据兼容。

正常数据目录继续使用 `%LOCALAPPDATA%\FocusGarden`，不因改名新建一套历史记录。0.3 的专注数据库、Token 缓存、背景、限制设置和浏览器配对数据继续使用；新增成长与布局数据库独立保存。新旧版本共用单实例标识，同一 Windows 登录会话中只运行一个实例。

| 模块 | 职责 |
| --- | --- |
| `FocusGarden.App` | 窗口、计时协调、限制、系统事件、统计、Token 导入和星球页面 |
| `FocusGarden.Timing` | 单调时间累计器 `FocusClock` |
| `FocusGarden.Core` | 专注与应用时长存储、Token 索引、成长规则、多星球和布局存储 |
| `PlanetView3D` / `PlanetView3DScene` | 三维球体、景观、动画、相机交互和地块命中 |
| `browser-extension` | 网站临时阻止规则、配对、同步与解除 |

## 成长规则与六个月周期

每天按本地自然日，使用启用星球后新增的有效专注秒数 S 和新增 Token 数 N：

```text
专注点 F = min(120, floor(S / 60))
Token 点 T = min(60, floor(15 × log₂(1 + N / 100000)))
共同助力 B = min(20, floor(min(F / 3, T)))
每日成长 G = F + T + B，最多 200 点
```

两项来源均可独立贡献成长；同时使用时获得共同助力。Token 点递减并封顶：10 万 Token 为 15 点，30 万为 30 点，150 万达到 60 点上限。它只是养成权重，不表示学习质量、工作成果或费用。休息不计专注，提前结束和中断已保存的实际时间仍有效，不扣已有成长。

| 等级 | 阶段 | 累计成长门槛 | 最低星龄 | 景观与解锁 |
| --- | --- | ---: | --- | --- |
| 0 | 初生星球 | 0 | 启用时 | 荒凉地表、海洋和山石 |
| 1 | 森林萌芽 | 150 | 无额外月份要求 | 植被；树木、花丛可布置 |
| 2 | 生命栖息 | 1,200 | 1 个自然月 | 小动物出现 |
| 3 | 定居家园 | 3,000 | 2 个自然月 | 小屋可布置 |
| 4 | 风能文明 | 5,500 | 3 个自然月 | 风车、观测塔可布置 |
| 5 | 星际绿洲 | 9,000 | 5 个自然月 | 天文台可布置，夜间可能出现极光 |

阶段同时要求成长值和星龄。月份按该星球 `ActivatedAt.AddMonths(n)` 判定，保留启用时刻，月末按日历规则处理；六个自然月不是固定 180 天。满六个月即可开拓新星球，无需达到最高等级或刷满成长值；不会自动清空旧星球，也可继续建设。每颗星球只能开拓一次后继星球。

`PlanetGrowthStore` 保存多颗星球的名称、启用时刻、随机种子、当前选择与成长分配。新星球从 0 点开始，旧星球与其布局保留；选择旧星球后，后续成长可继续分配给它。切换和开拓前先结算已有记录，专注、休息或用量导入进行中不执行切换。

### 防重复与记账边界

- 首次启用保存当日已有专注秒数作为基线，旧日期和基线以前的专注不兑换成长。历史仍保留在原统计中。
- 首次绑定 Token 来源以全局星球启用时刻为截止；更换来源或切回旧来源，以切换时刻开始新观察期。同一天内的筛选由导入器按事件时间完成。
- 每日专注和当前来源观察期内的 Token 汇总保存最高已见值。重复刷新、缺失、数值下降及恢复均不重复奖励，也不扣除已奖励成长。
- 各来源观察期的新增 Token 合并为每日永久累计。每日目标成长只奖励正差额，高水位、每日奖励和星球份额在同一事务中更新。
- 防重复状态和每日 200 点上限由所有星球共享；切换不重算旧记录。新增成长只分给当前星球。“今日共”是全局每日值，“本星球”是当前星球所得份额。

数据库保证正常操作中的记账一致性，不提供服务器时间验证或防篡改服务；系统时间和本机日志是本地信任输入。

## 三维星球与布局

星球采用 WPF `Viewport3D`、实际三维网格、光照和透视相机。左键拖动旋转，滚轮缩放，双击或“重置视角”复位。专注期间缓慢转动，云和动物使用轻量动画；布局模式暂停相关动画，便于选中物体。

每颗星球有 **32 个固定地块**，每块最多一个可编辑物品。编辑采用点击地块吸附：选择类型后放置，选中已有物品后可移动到空地块、按 90° 旋转或收起。每次成功操作立即写入 `planet-layout.db`，按稳定的 `PlanetId` 隔离。解锁后布置不消耗成长值，收起后可重新放置。

| 类型 | 所需等级 | 每颗星球上限 |
| --- | ---: | ---: |
| 树木 | 1 | 12 |
| 花丛 | 1 | 12 |
| 小屋 | 3 | 8 |
| 风车 | 4 | 3 |
| 观测塔 | 4 | 2 |
| 天文台 | 5 | 1 |

这是固定地块布局，不是任意坐标拖放、地形雕刻、道路绘制或完整沙盒建造。自动生成的山石、植被、动物和天气不属于可编辑地块物品。动物为装饰性活动，没有繁殖、食物或生存模拟。

天气由星球种子和本地三小时时段确定，同一时段刷新不会重新抽取；晴朗、多云、轻雨均可出现，最高阶段夜间可能有极光。夜间为本地 19:00 至次日 06:00。天气不连接真实天气服务，也不因休息或中断惩罚星球。

## 专注、应用时长与统计

专注使用 `Stopwatch` 与 `FocusClock` 累计实际有效秒数，不用系统时钟倒推已完成时长。达到计划时长才标记完成；紧急退出和中断保留已保存秒数。系统休眠、锁屏、注销或超过五秒的计时回调间隙会中断本轮，停顿不补计。重启恢复遗留会话时只保留最后检查点，不把停机时间算作专注。

`focus.db` 中的会话与按日累计在同一事务更新，跨午夜、跨年按当时本地日期分配。年度热力图包含所有状态的实际秒数，完成番茄数只取完成记录；休息不计入。最近记录显示 12 条，CSV 最多导出最近 100,000 条，采用 UTF-8 BOM 并防止任务文本触发表格公式。

自选背景复制到数据目录，原图不修改；主页和全屏页使用暗色蒙层保持文字可读，并显示当前日期时间。当前时钟与专注计时使用不同时间源。

应用时长每约 250 毫秒采样前台进程，只有前后为同一应用、未锁定、两端空闲均少于 60 秒且间隔少于三秒时才累计。每约五秒保存，按本地日期分配。只保存进程名、日期和秒数，不保存窗口标题、网址或输入内容；不补算启动前、后台、休眠或未知间隔。这是前台活跃使用的近似统计。

## Token 日志与立体日历

`CodexUsageImporter` 只读扫描所选 Codex 根目录内 `sessions` 和 `archived_sessions` JSONL，提取 `event_msg/token_count` 用量记录。默认沿用保存的目录，否则使用 `CODEX_HOME` 或用户目录下 `.codex`。历史日志格式可能变化，不能视作长期稳定的账单接口。

缓存独立保存到 `codex-usage.db`，仅索引用量元数据，不保存或展示会话正文。副本、归档和重复累计按事件信息去重；缺失历史只使用有证据的增量，不凭空补算。缓存输入已包含在输入中，推理输出已包含在输出中，不能再次相加。不同来源查询隔离，导入失败时不把旧来源冒充新来源。

Token 日历仍为十二个月、4×3 排列的三维柱图，支持旋转、缩放、悬停数值与平方根/线性柱高。灰格表示无可读取记录，不代表账号实际使用为零。程序可手动刷新或运行期间每两分钟刷新；关闭后不继续读取。

**Token 数据是本机日志估算，不是官方费用账单、余额或账号限额百分比。**其他设备、云端、删除的记录、未落盘事件或不支持的格式可能不被覆盖。年度日历可展示历史，而星球只奖励符合启用时间及来源观察期的新记录，因此二者数字可以不同。

## 限制与紧急退出

应用限制按进程名精确匹配前台窗口并请求最小化，不强制结束进程。系统桌面、任务管理器、程序自身和部分恢复工具受保护；管理员窗口、改名程序和特殊窗口可能绕过，后台任务不受控制。

浏览器扩展通过 `http://127.0.0.1:17839/state` 只读获取状态，使用本机随机配对码。MV3 临时规则只阻止目标域名及子域的新主页面导航，不读取网页正文；已加载页面、现有媒体流、部分单页应用和未启用扩展的浏览器不受覆盖。通常约五秒同步，并有定时唤醒和约十五秒租约；浏览器挂起时清理脚本也会暂停，不能承诺固定解除时限。

`Ctrl + Alt + Esc` 注册成功时立即结束本轮；主窗口和全屏保留紧急退出按钮，全屏 Esc 和关闭操作进入确认。快捷键注册失败会提示改用按钮。网站限制可通过“解除限制并取消配对”或禁用扩展恢复。

全屏是单个显示器上的普通置顶窗口，不是 Windows 安全桌面或系统锁屏；不承诺阻止系统快捷键或绝对无法退出。不安装内核驱动，不修改 hosts、DNS 或防火墙规则。

成长测试覆盖公式、上限、历史排除、重复与回退、来源切换、跨日跨年、事务失败回滚、持久化、六个自然月及多星球分配。布局与渲染另有独立检查；原有计时、存储、限制及 Token 导入测试继续适用。本文件描述实现和操作边界，不宣称已经完成真人桌面点击验收、真实浏览器配对拦截或所有 Windows 显示配置的检查；实际验证范围以本次交付的验收记录为准。


## 0.5 渲染补充

地表为单个 5,120 三角形平滑球面，采用每等级缓存的 1024×512 程序生成经纬贴图。UV 经度接缝展开、左右像素一致、极点采样位于首末行中心。小景观共享冻结圆体/盒体网格，材质按颜色缓存。成熟晴天自然场景约 12.1 万三角形；暖缓存场景构建的单次本机观测约 15 ms，不等同于所有设备的帧率保证。

展开窗口重用原场景控件和原布局工具栏，关闭后归还父容器，不创建第二份存档。主视图、展开观景与展开布置均继续使用原来的可见性和编辑状态控制动画。

## 0.6 地表近景

同一 `Viewport3D` 在全星球与地表近景两种相机配置间切换，不重建场景或复制地表图片。近景相机沿固定球外径向调整距离，根据球体角半径与视口纵横比计算真实上方切线，使中央地平线位于视口约 56% 高度；地表超出画框下沿，星空继续使用原背景。

逻辑经纬观察角与具体渲染变换分离，近景添加固定俯仰偏移，将当前区域带到近处地表。两个模式独立保存本次运行内的缩放，缩放范围受限以防相机进入球体。切换和缩放只改相机及变换，不改变成长等级、地块编号或建筑列表。

近景输入灵敏度降低，停止整球专注自动转动；动物与云朵动画沿用原变换。原射线命中检测用于近景布置，遮挡规则保持一致。新模式不写入数据库，关闭程序后恢复默认全星球视角。
