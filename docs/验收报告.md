验收日期：2026-10-27。版本：Windows x64，自带 .NET 8.0.22。工作源码位于用户指定项目目录，交付包与旧版分开保存。

## 结论

Release 构建和自包含发布成功；已发布的 `专注星球.exe` 在独立数据目录完成隐藏启动检查，退出码 0，能构造主窗口和 3D 场景并报告 Ready=true。已执行 169 项自动检查，全部通过；离屏渲染已检查初生星球、成熟家园、布局、晴天和云雨场景。此处的离屏检查不等于真人点击整套桌面流程。

主窗口集成使用临时目录与合成记录，没有显示桌面窗口，也没有读取或修改用户真实星球。数据库故障测试主动拒绝成长写入，确认结算失败时不会启程；移入已占用地块失败后，保留原物品与原选择。

3D 命中检测在离屏场景确认可点击 16 个朝前地块，背面受球体遮挡。编辑模式暂停动态；动物和云朵使用变换更新，不在每一帧重建网格。通过滚轮可以放大观察。

## 渲染检查

已检查整体主窗口和独立星球的实际 WPF 渲染，修正布局下拉框错误显示内部对象名称的问题。文字使用明亮文字与深蓝背景；星球外为星空；初始场景呈灰褐色荒凉地貌，成熟示例有植被、动物、建筑和环带。

交付的成熟、布局和天气图片明确是合成演示，不能作为用户已积累专注或 Token 的证据。真实首次启用仍从零成长开始。

## 数据与兼容

正常路径仍为 `%LOCALAPPDATA%\FocusGarden`。原专注、设置、背景、应用时长和 Token 缓存继续使用，新增 `planet.db` 与 `planet-layout.db`。防重复高水位与每日上限由所有星球共享，每颗星球独立保存成长、名称和布局。程序升级不主动删除旧版文件或用户数据。
