## 桌面观察及修正

已启动 WPF 初版，观察到真实主窗口和可访问控件。初次截图发现窗口样式没有继承，导致背景与文字颜色错误；源码已改为显式引用主题。代码审查另修复了带点进程名匹配、数据库异常后再次开始的恢复、热键失败提示和全屏内容缩放。

用户按物理 Esc 停止 computer-use 后，所有桌面自动操作停止。后续工作只进行源码修正、非 UI 检查和构建打包。修正后的最终界面尚未重新截图验收，不宣称视觉和交互全部通过。

最终 Windows x64 自带运行时发布构建成功。交付版本含 .NET 8.0.22 运行时，不需要目标电脑预装 .NET。源码与便携包一起交付；包内不包含测试数据库、个人记录或配对码。

## 复现自动检查

在源码目录执行：

```powershell
dotnet run --project tests/FocusGarden.Core.Tests/FocusGarden.Core.Tests.csproj -c Release
dotnet run --project tests/FocusGarden.Timing.Tests/FocusGarden.Timing.Tests.csproj -c Release
dotnet run --project tests/FocusGarden.Bridge.Tests/FocusGarden.Bridge.Tests.csproj -c Release
node --test browser-extension/tests/controller.test.js
```

真实浏览器测试脚本另需 Playwright 与可用的 Edge 环境，见扩展目录说明。它不作为普通用户运行程序的依赖。
