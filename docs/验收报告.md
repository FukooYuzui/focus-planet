# 专注星球 0.5 验收报告

验收日期：2026-10-27。版本：Windows x64，自带 .NET 8.0.22。0.5 交付包与旧版分开保存，继续兼容现有本地记录和家园布局。

## 本次结论

0.5 Release 构建和自包含发布成功。本次执行的 40 项自动检查全部通过：16 项几何检查、14 项星球视图检查、10 项主窗口集成检查。已发布并改名后的 `专注星球.exe` 在新的独立数据目录完成隐藏安装检查，结果为 `Ready=true`、`Version=0.5.0`、退出码 0，窗口标题为“专注星球 0.5 · Focus Planet”。

实际 WPF 离屏预览已生成，已目视检查荒凉初生与展开布置场景。离屏渲染及隐藏初始化不等同于真人点击整套桌面流程；本报告不将此前版本的测试计入本次执行数。

|---|---:|---|

| **本次总计** | **40** | **全部通过** |

主窗口集成使用临时目录与合成记录，没有显示桌面窗口，也没有读取或修改用户真实星球。数据库故障用例主动拒绝成长写入，确认结算失败时不会启程，重试后仍计入原星球；移入已占用地块失败后，保留原物品与原选择。

展开观景和展开布置复用同一个星球场景，返回时恢复原布局父容器。视图检查覆盖相机默认构图、前方地块命中与背面遮挡；动物和云朵通过变换更新，避免逐帧重建网格。编辑模式暂停动态，方便布置。

## 前版验证记录

0.4 曾执行 169 项自动检查并全部通过，涵盖专注存储、计时、浏览器桥接、背景、应用时长、Token 导入与日历、成长、布局及当时的视图和集成流程。该结果属于前版历史证据。

本次重新执行上表列出的 40 项检查。其余模块的历史通过结果没有被标记为 0.5 本次重跑；用户可运行源码所附测试项目进行进一步回归验证。

## 画面与交互范围

0.5 主视图高度提高，加入“展开观景”和“展开布置”，星球支持拖动旋转、滚轮或按钮缩放、视角重置及 Esc 返回。连续海洋—浅海—沙滩—陆地色彩过渡与平滑光照已用于球体；荒星增加陨石坑、层状岩、岩群和晶簇，成长阶段增加植被、动物与建筑细节，背景为宇宙星空与蓝紫星云。

交付预览包括初生、成熟、云雨、展开观景与展开布置。成熟、布局和天气预览均为合成演示，不能作为用户已积累专注或 Token 的证据。真实首次启用仍从零成长开始。

## 数据与兼容

正常数据路径仍为 `%LOCALAPPDATA%\FocusGarden`。原有 `focus.db`、`codex-usage.db`、`planet.db`、`planet-layout.db`、设置及背景继续使用。32 个球面地块的坐标与编号保持不变，原有建筑不会因美术升级移动。程序升级不主动删除旧版文件或用户数据。

本次隐藏安装检查使用新建的独立验收目录，不访问正常用户存档。发行包不应包含验收数据库、浏览器配对密钥、Token 原始日志或用户图片。

## 未在本次执行的检查与功能边界

- 未执行真人桌面拖拽、全屏紧急快捷键与真实浏览器配对拦截的端到端点击验收。
- 未逐一验证所有显卡、缩放比和多显示器组合；场景使用 Windows 自带 WPF 3D 渲染。
- 六个月规则的完整边界验证属于 0.4 的受控时间测试；本次集成另验证合成成熟星球恢复，没有快进系统时钟或真实存档。
- 家园采用 32 个固定球面地块吸附，未实现任意地形修改、道路编辑、战斗、联机或云同步。
- 本地日志是尽力兼容的 Token 估算，包含缓存输入，不是费用或账号额度。时间和数据由本机提供，不提供防篡改服务。

源码附各测试项目，可用 `dotnet run --project tests/<项目>/<项目>.csproj -c Release` 复查；扩展逻辑测试在 `browser-extension` 下执行 `npm test`。正式程序支持 `--check-installation --data-dir <独立验收目录>`，仅隐藏初始化并写入安装检查结果，不显示主窗口。
