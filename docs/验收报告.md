# 专注星球 0.11.0 验收报告

## 本版行为

工作日记按日期保存为独立 Markdown 文件，支持软件内编辑和轻量离线阅读预览。
可选择次日首次启动自动整理前一天；已有正文跳过，不自动追补更早日期。
公众下载包默认关闭自动整理，需在日记设置中开启。
专注过程中只读；关闭软件保存编辑，失败则保留窗口。
重新生成另存草稿，手动替换前备份旧文；外部修改冲突拒绝覆盖。

来源是本地日期实际保存秒数、最近完成列表中的当天说明，以及可选 Codex 对话节选。
当前长期任务状态单独标注，不冒充当天新增进度。有限扫描会向摘要标记截断与错误。
对话来源不包含工具结果、系统提示或凭据文件。基础遮盖不能识别所有私人内容。
生成会向 Codex 发送所选材料，使用其登录及对应额度，软件不提取密钥。

官方 codex exec 在独立只读、临时会话中运行，关闭命令执行、应用连接和网页搜索。
用户自定义 Codex 配置不加载，进程无控制台窗口，输入从 stdin 传递而非拼接命令。
三分钟超时、可取消、输出有界；停止只针对本次生成进程及其子进程。
失败不写半篇日记，不接管其他 Codex 对话，也不触发专注限制。
