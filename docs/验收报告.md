# 专注星球 0.6 验收报告

版本：0.6.0，Windows x64，自带 .NET 8.0.22。

## 本次结论

新增“全星球 / 地表近景”切换。地表近景使用同一真实 3D 场景，上方保留星空，下方呈现局部弧形地表；树木、生物和建筑可近距离观察。拖动、方向键、滚轮、缩放按钮及当前模式重置均保留。

Release 构建通过，0 警告、0 错误。本次执行 32 项自动检查，全部通过：22 项星球视图检查、10 项主窗口集成检查。已发布并改名后的“专注星球.exe”在新的独立数据目录完成隐藏安装检查，Ready=true、Version=0.6.0、退出码 0。

## 视图验证

22 项检查包含原有球面、地块、布局、动画和纹理检查，以及新增的 8 项近景检查：

- 实际 WPF 射线命中验证弧形地表位于画面下方，顶部保留天空，球面延伸到左右和底部画框之外。
- 900×600、1400×500、500×760 三种控件尺寸下，中央地平线约位于可视区域 56%～57% 高度。
- 极端缩放和窗口变化时相机仍在球体及当前景观外；宽屏调整真实相机视野以保持局部地表构图。
- 切换模式分别恢复缩放，逻辑观察方向连续，不重建场景、不改变建筑列表与选择地块。
- 实际滚轮事件能调整近景，一格不会直接到边界；缩放值受安全范围约束。
- 近景命中检测找到 5 个可见固定地块，沿用原遮挡和编辑规则。
- 重置保留当前模式；近景专注中暂停整球自动转动，同时动物和云朵仍通过变换活动。

测试过程中发现特别宽的窗口可能露出球体侧缘，已修复并对上述三种尺寸重新验证。

## 主窗口与数据

10 项集成检查使用独立临时数据库和合成记录。除专注只入账一次、历史排除、成长恢复、改名与布局持久化、失败回滚外，本次增加断言：近景模式和缩放在展开观景、展开布置、关闭展开窗口与主页切换后均保留。

正常数据仍位于 `%LOCALAPPDATA%\FocusGarden`，本次没有修改存储结构、成长公式、32 个地块的编号与坐标，也没有读取或更改用户真实成长和布局。近景选择仅保存在当前程序运行期间，下次启动默认回到全星球。

## 视觉检查与范围

已生成实际 WPF 离屏预览，检查近景、荒凉初生、成熟家园及展开布置的构图、文字和地块标记。演示景观使用合成数据，不代表用户已获得对应成长、建筑或 Token 记录。首次启用仍按真实进度显示荒凉星球。

本次完成自动检查、真实 WPF 离屏渲染和发布程序隐藏初始化；未执行真人桌面鼠标拖动、全屏紧急快捷键、浏览器拦截等完整端到端操作，也未逐一验证所有显卡和显示缩放配置。前版其余模块的历史测试不计入本次 32 项。

源码附带检查项目：`tests/FocusGarden.PlanetView.Tests` 与 `tests/FocusGarden.PlanetIntegration.Tests`。便携程序支持 `--check-installation --data-dir <独立目录>`，用于隐藏初始化核验。
