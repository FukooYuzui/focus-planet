# 专注花园 FocusGarden 0.3 使用说明

专注花园是一个 Windows 桌面番茄钟，提供全屏倒计时、自选专注背景图片、当前日期时间、应用与网站使用限制，以及保存在本机的专注记录和主页年度热力图。0.3 在专注主页加入每日前台应用使用时长与 Codex Token 立体日历。它用于帮助自己保持专注；紧急退出始终保留，限制也可以通过系统工具或禁用浏览器扩展绕过。

## 1. 启动

1. 完整解压 Windows x64 便携包，保留其中的文件夹结构。
2. 双击 `FocusGarden.exe`。便携包自带运行时，不需要另行安装 .NET。
3. 打开后先进行一轮短时专注，熟悉紧急退出入口，再设置平时使用的时长。

程序不要求登录。一个 Windows 登录会话内只运行一个专注花园实例；再次启动时会提示切换到现有窗口。

### 从 0.1 / 0.2 升级

先结束当前专注并正常关闭旧程序，再将 0.3 便携包完整解压到一个新文件夹，从该文件夹启动 `FocusGarden.exe`。启动后确认窗口标题含有 `0.3`；若仍显示旧标题，请检查是否打开了旧版快捷方式或先前的验收程序。

0.3 继续使用相同的本机数据目录，兼容已有专注记录、限制设置、背景图片与浏览器配对码。无需删除 `%LOCALAPPDATA%\FocusGarden` 或重建数据库。新旧程序文件夹可以分别保留，运行时应只开启其中一个版本。

## 2. 开始专注与休息

在左侧选择「开始专注」：

1. 填写本轮任务，例如“读完一节教材，整理三条笔记”。任务留空也可以开始。
2. 设置专注时长，界面支持 1–180 分钟；休息时长支持 1–60 分钟。
3. 勾选「全屏沉浸」后开始，将显示单个屏幕上的全屏倒计时；取消勾选则使用工作模式，便于在电脑上学习或工作。
4. 点击「开始专注」。本轮开始后不能修改时长或限制列表，修改应在本轮结束后保存。

工作模式下可点击「进入全屏」。全屏是普通桌面上的无边框置顶窗口，不是 Windows 系统锁屏，不覆盖全部显示器，也不保证阻止 Alt+Tab、Windows 键、任务管理器等系统操作。

专注到时自动结束并解除本轮应用限制。点击「休息一下」手动开始休息；休息期间不会启用应用或网站限制，也不计入专注记录。第一版不自动连续启动下一轮专注。

### 当前日期与时间

番茄钟主页倒计时区域右上方显示「现在」和本机当前时间，格式为 `HH:mm:ss`，下方显示日期与星期。全屏专注页同样显示当前日期时间。它们与「本轮倒计时」或「本轮剩余」分开显示；主页在尚未开始或本轮结束后也会继续走时。

### 选择专注背景图片

1. 在番茄钟主页点击「选择背景图片」。
2. 选择一张不超过 25 MB 的 JPG/JPEG、PNG 或 BMP 图片。过大或无法解码的图片会被拒绝，原有背景保持不变。
3. 选择成功后，主页倒计时区域与全屏专注页同步使用这张图片，图片上覆盖暗色蒙层以保持文字可读。图片按区域铺满，边缘可能被裁切。
4. 点击「恢复纯色」可取消图片背景。专注或休息进行中，不能更换或恢复背景，请在本轮结束后操作。

图片选择会在本机保存，重启后自动恢复。程序将图片复制到自己的数据目录，不会修改原始文件；即使原图随后移动，已导入的副本仍可使用。恢复纯色不会删除原图或已导入的图片副本。

## 3. 配置应用限制

在左侧选择「使用限制」：

- 每行填写一个进程名，例如 `notepad.exe`，不要填写程序路径。
- 也可以点击「刷新运行列表」，选择有窗口的程序，再点击「加入列表」。
- 点击「保存限制设置」，下一轮专注时生效。

专注期间，切换到列表中的程序时，其前台窗口会被最小化。程序不会被强制结束，已打开的文件仍保留。限制不会停止后台任务或后台音频，也不保证控制管理员权限窗口、改名后的程序或特殊窗口。

系统桌面、任务管理器、必要系统进程和部分恢复工具不能加入限制列表。结束专注后，之前最小化的窗口可以自行恢复。

## 4. 配置网站限制

网站限制需要在使用的 Edge 或 Chrome 中手动安装随包提供的扩展。要求 Chromium 120 或更新版本。扩展没有发布到浏览器商店，第一版使用本地加载方式。

### 安装与配对

1. 保留交付包内完整的 `browser-extension` 文件夹，安装后不要随意移动它。
2. Edge 地址栏输入 `edge://extensions`；Chrome 输入 `chrome://extensions`。
3. 打开「开发人员模式」，点击「加载解压缩的扩展」，选择包含 `manifest.json` 的 `browser-extension` 文件夹。
4. 在桌面程序的「使用限制」页，每行填写一个域名，例如 `bilibili.com`，再点击「保存限制设置」。请勿填写 `https://`、网址路径、端口或 `*`。
5. 点击桌面程序的「复制配对码」。
6. 打开浏览器工具栏中的「专注花园」扩展，粘贴配对码，点击「保存并连接」。
7. 开始专注后，可点击扩展的「立即同步」确认当前限制列表。

域名包含其子域：`example.com` 会覆盖 `www.example.com`，不会覆盖 `notexample.com` 或 `example.com.evil.test`。不同浏览器或不同浏览器配置文件需要分别加载与配对。

### 限制范围

扩展阻止目标域名的新主页面访问，不读取网页正文。已经加载的页面不会自动关闭或停止播放；单页应用中的部分站内操作、离线内容、其他浏览器以及未启用扩展的隐私窗口可能仍可使用。

被限制时，浏览器会显示自己的请求阻止页面。专注结束、限制解除后，刷新该页面即可重新访问。

扩展通常约每 5 秒同步，并使用浏览器定时唤醒机制辅助恢复。桌面结束、紧急退出或断联后，扩展在下次运行并同步时解除限制。浏览器完全挂起时不能承诺固定解除时限；显示「已连接」也只代表通信成功，实际拦截应以新访问测试为准。

## 5. 紧急退出

- **立即退出：**按 `Ctrl + Alt + Esc`，结束当前专注并解除应用限制。
- **按钮退出：**点击可见的「紧急退出」，确认后结束。全屏中的 `Esc` 和关闭操作也会打开退出确认。
- **快捷键被其他软件占用：**主界面会提示注册失败；请使用紧急退出按钮，不要依赖该快捷键。
- **网站仍被阻止：**打开浏览器扩展，点击「解除限制并取消配对」；也可以在浏览器扩展管理页禁用扩展。取消配对后，后续网站限制需要重新配对才会生效。

紧急退出会保留已经写入的实际专注时长，记录状态为「提前结束」，不会记作一个已完成番茄。

## 6. 休眠、中断与异常退出

系统休眠、锁屏或注销会结束当前专注，记录为「中断」。如果计时回调出现超过 5 秒的停顿，也会中断本轮，停顿时间不计入专注。这一处理较保守：电脑严重卡顿也可能触发中断。

若程序被任务管理器结束、发生崩溃或断电，下次启动会把遗留的进行中记录恢复为「中断」，保留最后成功保存的时长。停机期间不会自动补算为专注时间；尚未写入的最后一小段时间可能丢失。

没有提供“暂停后继续同一轮”的功能。中断后可以重新开始一轮。

## 7. 热力图、统计与导出

年度专注热力图位于左侧「开始专注」对应的番茄钟主页，向下滚动可见。每格对应当地日期的一天；悬停可查看日期与时长，左右箭头可切换年份。专注进行时约每 30 秒刷新，结束后会更新本轮结果。它记录专注时长，与下方的 Codex Token 日历分别统计。

打开左侧「专注统计」查看汇总与记录：

- 「今日专注」累计今日实际保存的专注时长，包含完成、提前结束及中断记录，休息不计入。
- 「所选年完成番茄」只统计状态为「已完成」且结束时间属于所选年份的轮次。
- 「所选年专注天数」统计有实际专注秒数的日期。

统计页中的「所选年」与主页热力图选择的年份一致；需要切换年份时，返回番茄钟主页操作。

热力图颜色从浅到深表示：0、少于 25、25–49、50–99、至少 100 分钟。跨午夜的专注按各天实际经过的时间分配；跨年也分别进入对应年份。界面分钟数可能经过四舍五入，数据库与 CSV 保留整数秒。

点击「导出 CSV」，选择保存位置。导出包含任务、开始与结束时间、计划秒数、实际秒数和状态，可用 Excel 打开。最近记录区只显示最近 12 条；CSV 最多导出最近 100,000 条记录。

## 8. 每日应用使用时长

在专注主页查看「应用使用时长」，或点击左侧「应用时长」直接定位。列表按已记录时长从长到短排列，显示进程名、时长及当天占比。左右箭头可切换日期，「今天」返回本机当前日期。

「记录前台应用时长」默认开启，取消勾选可暂停，重新勾选后继续；开关会保存到本机，下次启动沿用。记录与番茄轮次独立：只要程序在运行且统计已开启，即使尚未开始专注也会记录。

计时口径如下：

- 只统计当前前台应用，且最近 60 秒内有过操作。持续没有操作满 60 秒后暂停，恢复操作后再开始有效采样。
- 锁屏、休眠、停留桌面或系统画面，以及无法确定归属的应用切换和长采样停顿不补计。
- 应用在后台运行或后台播放音频不会增加时长；专注花园自身处于前台时可能出现在列表中。
- 应用按进程名合并，例如 `msedge.exe`。浏览器按整个进程统计，不按网页或标签分开。
- 只保存进程名与时长，不读取或保存窗口标题、网页地址、输入内容。

记录从本程序运行后开始，无法补算此前的使用历史。使用时长约每 5 秒保存并刷新，跨午夜按本地自然日分配；异常退出可能丢失最后尚未保存的少量时长。读取书籍、视频等场景若超过 60 秒没有操作会被暂停计入，因此这里是“前台活跃使用”的近似统计，不等同于全部屏幕观看时长。

## 9. Codex Token 立体日历

在专注主页向下滚动，或点击左侧「Token 日历」直接定位。页面显示所选年份累计 Token、今日 Token、有记录天数，以及按 4 列 × 3 行排列的十二个月立体日历。

### 读取本机记录

1. 程序启动时尝试读取本机 Codex 数据目录。程序运行期间可每 2 分钟自动刷新，也可关闭自动刷新，或点击「刷新本机用量」手动读取。
2. 默认优先使用此前保存的目录，其次使用 `CODEX_HOME` 环境变量，未配置时使用用户目录下的 `.codex`。
3. 若找不到数据，点击「选择 Codex 数据目录」，选择包含 `sessions` 或 `archived_sessions` 的根目录。
4. 首次历史读取可能较慢，状态行显示完成结果；读取在后台进行，期间可点击「取消读取」。后续刷新会跳过未变化的文件。手动取消后至少等待下一个 2 分钟自动刷新间隔，不立即重试；关闭程序后不继续自动读取。

原始 Codex 日志只读。读取时会扫描日志文件，仅提取和保存用量元数据，不保存或展示会话正文。缓存保存在专注花园自己的独立 `codex-usage.db`，与专注记录数据库分开。源目录改变后，以当前选定数据源进行汇总。

### 查看与操作

- 左右年份按钮切换年度。
- 按住鼠标左键拖动旋转，滚轮缩放；将鼠标移到某一天查看日期与 Token 数。
- 「柱高」可选择「平方根」或「线性」。平方根让较小用量更容易看见；线性柱高与用量成正比。切换只改变图形高度，不修改统计数值。
- 双击图形或点击「重置视角」恢复默认角度。数字缩写 `K`、`M`、`B` 分别表示千、百万、十亿，悬停在汇总数字上可看完整值。

这里是本机日志中可读取并去重后的 Token 用量估算，包含缓存输入。它不是账号余额、剩余使用额度、额度百分比或费用账单，也不保证覆盖其他设备、远端会话、已删除或尚未写入日志的使用。

灰色日期格表示没有可用的本机记录，不代表实际用量为零。日志格式变化或部分文件不可读会影响统计；状态行中的错误数量应与图表一起查看。

## 10. 本地数据与备份

正常运行的数据目录为 `%LOCALAPPDATA%\FocusGarden`。可将此地址粘贴到文件资源管理器地址栏。

| 文件 | 用途 |
| --- | --- |
| `focus.db` | SQLite 数据库，包含设置、专注记录、按日累计与每日应用使用时长 |
| `codex-usage.db` | 本机 Codex Token 用量缓存与去重索引 |
| `dashboard.json` | 应用时长记录开关及 Codex 数据目录选择 |
| `browser-pairing.key` | 本机浏览器扩展的配对码 |
| `focus.db-wal`、`focus.db-shm` | 程序运行时可能存在的 SQLite 辅助文件 |
| `appearance.json` | 专注背景图片的选择信息 |
| `backgrounds` 文件夹 | 程序导入的本地背景图片副本 |

`codex-usage.db` 在运行时也可能有同名的 `-wal`、`-shm` 辅助文件。备份时先结束专注并正常关闭程序，再复制整个数据目录。恢复时也先关闭程序。不要在数据库正在写入时单独移动或覆盖数据库文件。

删除便携程序文件夹不会自动删除上述数据。配对码用于授权本机扩展读取当前限制状态，不要公开发布；更换或删除配对码后，需要重新配对扩展。

## 11. 常见问题

**应用使用时长为什么与 Windows 屏幕时间不同？**本程序只记录它运行期间、前台且 60 秒内有操作的应用，不补历史、不累计后台时间，并保守跳过切换和长停顿。看视频或阅读时长时间不操作也会暂停统计。

**Token 日历全部是灰色。**先确认数据目录正确并点击「刷新本机用量」。灰色表示当前本机日志没有可用记录，不表示账号没有使用；账号额度应以 Codex 自身的额度显示为准。

**网站没有被拦截。**确认浏览器中安装并启用了扩展、桌面正在专注、限制列表已保存，然后打开扩展点击「立即同步」。使用一个新的页面导航测试；已加载页面继续显示或播放不代表扩展失效。

**桌面显示“本机连接服务不可用”。**此时网站限制无法正常同步，倒计时和应用限制仍可单独使用。检查是否还有另一份程序运行，或本机端口被占用。无需修改系统 hosts、DNS 或防火墙规则。

**打开后看到“已经在运行”。**切换到已有窗口即可；程序不会并行开启两个计时实例。

**关闭程序后网站仍暂时被阻止。**等待扩展恢复运行并同步，或直接点击「解除限制并取消配对」/禁用扩展。浏览器全部退出后重开，临时限制规则也不会永久保留。

**为什么工作模式还能打开没有列出的软件？**应用限制只针对你明确保存的进程名。第一版提供可恢复的自律辅助，不实施操作系统级封锁。
