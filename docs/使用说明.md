# 专注星球 MVP 0.7.5 使用说明

专注星球是一款 Windows 桌面番茄钟：用专注时间与本机 Codex Token 用量帮助荒凉小星球逐渐拥有植被、生物和建筑。你可以旋转观察星球、布置家园，六个自然月后开拓下一颗，同时保留旧家园。原有全屏专注、自选背景、当前时间、专注热力图、应用时长、Token 日历、统计和使用限制均保留。

## 0.7.5 使用变化

专注保存、用量统计和星球更新改在后台执行，减少页面切换和布置家园时的等待。功能、模型细节和已有时长不变；隐藏页面返回时会显示最新数据，Token 立体日历首次打开时加载。

结束专注后，短暂显示“正在保存本轮记录”，保存结束后可以开始下一轮。正常关闭会等待已经开始的保存和 CSV 导出完成；若提示仍有记录未保存，程序会保持暂停，请检查磁盘后再次关闭，不要删除数据目录。开始等待期间若锁屏或休眠，返回后需重新点击开始。

## 地表近景：走近你的家园

0.7.1 更新了生物和自然景观模型，查看耳朵、羽毛、树冠、睡莲与山体细节时，推荐切换“地表近景”后点击“展开观景”。操作方式、成长条件及已保存布局继续沿用。

在星球画面右上方选择“地表近景”。画面上方保留星空，下方显示弯曲的地表；近处的树木、动物和建筑会放大，部分近景自然延伸到画框之外。

- 按住鼠标左键拖动，环顾星球的其他区域；点击画面后也可使用方向键。
- 滚轮或 ＋ / − 调整观察距离；双击地表、“重置视角”或 Home 恢复当前模式的初始方向与远近。
- 选择“全星球”回到总览。两种模式分别记住本次运行中的缩放值，切换不会重置家园或改变成长。
- 可以先选择近景，再点击“展开观景”或“展开布置”；返回主页时保留该视角。在近景中仍可点击可见地块布置已解锁物品。
- 近景关闭整颗星球自动旋转，动物和云朵仍然活动；拖动时或开启布置模式时暂停活动，便于观察及点击。

退出程序后下次默认回到全星球视角。近景显示自己的真实星球：新星球仍然荒凉，景物和建筑取决于已有成长与布置。

## 1. 启动与升级

1. 将 Windows x64 版本的 `专注星球.exe` 保存到常用文件夹；如果下载的是压缩包，先解压出此文件。
2. 双击 `专注星球.exe`。单个 EXE 已包含运行时、应用图标及浏览器扩展资源，无需携带 DLL、另装 .NET 或登录账号。随包文档和外部扩展文件夹为备用资料，不是程序启动的必需文件。
3. 确认窗口标题为“专注星球 0.7.5”，打开后默认进入“我的星球”。首次运行该版本会将所需原生运行库提取到 Windows 临时缓存，可能比后续启动稍慢；缓存与专注记录分开保存。

升级时，先结束专注并正常退出旧程序，再运行新版 EXE。你可以将它放在新文件夹，也可以替换旧的主程序。正常数据目录仍是 `%LOCALAPPDATA%\FocusGarden`，不随 EXE 的位置或版本变化；已有专注记录、背景、限制设置、Token 缓存和配对码保持兼容，无需搬运或删除数据库。新旧程序可以分别保留，但同一 Windows 登录会话只运行一个版本。若提示已经运行，请切换到已有窗口或退出旧版后再启动。

0.7.0 首次打开旧家园时，会先备份布局数据库，再升级可放置类型。专注记录的升级备份沿用 0.6.1 的保护机制。遇到备份或迁移错误时应保留数据目录，按提示解决后重试，不要删库重新开始。

## 2. 养成我的星球

星球页显示当前时间、天气、星龄、成长值、下一阶段条件和开放探索日期。可以在“星球档案”修改名字并点击“保存名字”。开局荒凉是正常状态；以前的专注与 Token 历史仍在统计页中，但不会让新启用的星球立即满级。

### 每天怎样获得成长

| 来源 | 规则 | 每日上限 |
| --- | --- | ---: |
| 专注 | 每满 1 分钟获得 1 点 | 120 点 |
| Token | 递减奖励；10 万约 15 点，30 万 30 点，150 万达到上限 | 60 点 |
| 共同助力 | 两项都有贡献时，按较小一项计算额外奖励 | 20 点 |

每天合计最多 **200 点**。只专注或只使用 Codex 也能成长，不必为了星球额外消耗 Token。展开“查看成长规则和六个月路线”可看到精确公式。

“今日共”是所有星球共享的每日成长，“本星球”是当天分给当前星球的份额。切换不会重新领取已有奖励。重复刷新、记录暂时缺失或减少不会扣掉已有成长，也不会在恢复后再次奖励。休息不计专注；提前结束或中断已保存的实际时间仍有效，不会让星球枯萎。

### 成长路线

| 阶段 | 成长值 | 最低星龄 | 新变化 |
| --- | ---: | --- | --- |
| 初生星球 Lv.0 | 0 | 启用时 | 荒凉地表、海洋、山石，可布置岩石庭园 |
| 森林萌芽 Lv.1 | 150 | 无额外月份要求 | 植被出现，解锁树木、花丛及其余新增景观 |
| 生命栖息 Lv.2 | 1,200 | 1 个自然月 | 自然生物出现，也可手动布置六种生物 |
| 定居家园 Lv.3 | 3,000 | 2 个自然月 | 可布置小屋 |
| 风能文明 Lv.4 | 5,500 | 3 个自然月 | 可布置风车和观测塔 |
| 星际绿洲 Lv.5 | 9,000 | 5 个自然月 | 可布置天文台，夜间可能出现极光 |

每个阶段同时需要足够成长值和星龄。点数够了但未到对应月份时，继续积累即可；页面会显示日期。晴朗、多云、轻雨和夜间效果由本地时间与星球种子生成，不是实时天气，也不是对未专注的惩罚。

### 六个自然月后开拓新星球

达到页面显示的开放探索时间后，点击“开拓新星球”。**无需满级或刷满成长值。**周期按启用时刻加六个自然月计算，不是固定 180 天；到期不会自动重置，也可继续建设原家园。

新星球从 0 点开始。旧星球的成长、名字与布局保留，可在“星球档案”下拉选择后点击“前往”。后续新成长帮助当前选中的星球。每颗星球只能开拓一次下一颗；新星球也有自己的六个月周期。

切换或开拓应在本轮专注或休息结束、Token 导入完成后操作。程序会先结算尚未读取的本机用量；若读取未完成，会留在原星球并提示先完成刷新。

## 3. 观察与布置家园

在星球图形区域按住鼠标左键拖动旋转，滚轮缩放。双击星球或点击“重置视角”恢复默认角度。地块在背面时，可先旋转找到它。

每颗星球有 **32 个固定地块**，每块最多一个可编辑物品。

1. 在“布置我的家园”下拉框中选择已解锁条目。条目按“建筑”“景观”“生物”分类排列，下方显示数量上限和搭配建议。
2. 点击“选择内容并放置”。程序会进入布局模式；也可手动勾选“开启布局模式”。
3. 点击一个空地块完成放置。成功后立即自动保存，无需另点保存按钮。
4. 调整已有内容时，先在布局模式点击它所在的地块，再选择“移动选中内容”“旋转 90°”或“收起”。动物会回到保存的地块位置并暂停活动，方便选中。
5. 移动时再点击目标空地块；若目标被占用，原内容保留。收起后可重新放置，布局操作均不消耗成长值。
6. 取消“开启布局模式”返回观察状态。动物恢复自动活动，已保存布局在重启和切换星球后仍保留。

### 让动物与附近景观一起活动

先放景观，再把对应动物放在邻近地块；取消布局模式后观察。动物会选择足够近、实际存在的匹配景观，自动短距离往返或停留，不需要点击触发。

| 生物 | 会选择的附近景观 |
| --- | --- |
| 兔子 | 草地、花丛、灌木 |
| 绵羊 | 草地、果树、树木 |
| 狐狸 | 灌木、树木、蘑菇丛 |
| 鸭子 | 池塘 |
| 鹿 | 池塘、树木、果树 |
| 蝴蝶 | 花丛、果树、蘑菇丛 |

自然生成的匹配景观也可能成为目标。相距太远、地面动物需要跨越明显水面，或周围没有适合景观时，不会强行前往，仍可保留原地小幅活动。岩石庭园用于布景，当前不作为动物互动目标。

观察状态下的活动位置不会写回存档。重新开启布局模式，动物会回到各自保存的地块，已有位置和朝向不会被自动活动覆盖。

切换到其他页面、将星球画面滚出可视区或最小化窗口时，场景动画会暂停以减少工作量；回到可见场景后恢复。**这只暂停画面动画，不会暂停专注倒计时。**场景使用一个约 120 毫秒的动画计时器，实际显示流畅度仍取决于设备、窗口大小与场景内容。

当前采用固定地块吸附，不支持任意坐标拖放、修改山海地形或绘制道路。自动生成的自然景观、自然生物和天气不能通过布局工具移动或收起；手动放置的生物可以编辑。动物没有喂养、繁殖或生存系统，也不会因你暂时离开而失去成长。

## 4. 开始专注与选择背景

点击“去专注”或左侧“开始专注”，填写任务，设置专注 1–180 分钟、休息 1–60 分钟。勾选“全屏沉浸”后开始会显示全屏倒计时；取消勾选可在普通桌面工作，开始后也可点击“进入全屏”。本轮进行中不能修改时长或限制列表。

需要减少提前退出时，在时长设置下勾选“严格专注”。每次点击“开始专注”都会再次确认本轮时长；选择取消不会开始计时或启用限制。确认开始后，开关和时长设置在本轮结束前不可修改，退出按钮会显示为禁用状态；全屏 Esc、Ctrl + Alt + Esc 和关闭窗口均不能提前结束本轮。

严格专注默认关闭，旧版本设置不会被自动启用。它只限制本应用内的提前退出；任务管理器、系统锁定、休眠、注销和关机仍可使用。系统中断或错误会解除限制，已保存时长保留，详见第 6 节。

专注完成后自动结束并解除本轮应用限制；点击“休息一下”手动开始休息。休息不启用限制、不计专注，也不自动开始下一轮。主页与全屏页均显示当前日期时间，与本轮剩余时间分开。

“选择背景图片”支持不超过 25 MB 的 JPG/JPEG、PNG 或 BMP。主页倒计时区和全屏页同步使用图片并加暗色蒙层；按区域铺满可能裁掉边缘。图片复制到数据目录，不修改原图，原图移动后副本仍可用。“恢复纯色”可取消背景。更换背景应在专注或休息结束后操作。

全屏是单个显示器上的普通置顶窗口，不是 Windows 系统锁屏，不遮挡全部显示器，也不承诺阻止系统快捷键或任务管理器。

## 5. 应用与网站限制

### 应用限制

在“使用限制”中每行填写一个进程名，例如 `notepad.exe`；也可“刷新运行列表”后选择程序加入。点击“保存限制设置”，下一轮专注生效。不要填写文件路径。

命中的前台窗口会被最小化，不强制结束进程，已打开文件保留。后台任务和音频不受影响；管理员窗口、特殊窗口或改名程序可能绕过。系统桌面、任务管理器、程序自身和部分恢复工具不能加入限制列表。

### 网站扩展

1. 在桌面程序“使用限制”页点击“打开扩展文件夹”。程序会按需导出内置的 8 个扩展文件，正常位置是 `%LOCALAPPDATA%\FocusGarden\browser-extension`；即使只复制了一个 EXE，也可以通过此按钮取得扩展。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`，开启开发人员模式，加载解压缩的扩展，选择上述文件夹。需要 Chromium 120 或更新版本。
3. 桌面“使用限制”页每行填写域名，如 `bilibili.com`，保存设置。不要写 `https://`、路径、端口或 `*`。
4. 点击桌面“复制配对码”，打开浏览器中的“专注星球”扩展，粘贴并点击“保存并连接”。旧版保留的扩展可能仍显示“专注花园”。
5. 开始专注后可在扩展点击“立即同步”。不同浏览器和配置文件需要分别安装与配对。

程序更新后，再点击一次“打开扩展文件夹”，然后到浏览器扩展管理页点击该扩展的“重新加载”。导出路径保持固定，移动 EXE 不影响已加载的路径；请不要单独移动数据目录中的扩展文件夹。程序只更新内置的 8 个同名文件，其他自建文件保留。使用显式自定义数据目录时，扩展位于该目录的 `browser-extension` 子目录。

以前若从发行包旁的扩展文件夹加载过扩展，可继续保留原位置；要改用本版固定路径，应移除旧扩展后重新加载程序导出的文件夹并配对。单 EXE 不会自动安装浏览器扩展，浏览器中的开发人员模式、加载和配对仍需手动完成。

限制覆盖目标域名及子域的新主页面访问。已加载页面不会自动关闭或停止播放；部分单页应用、离线内容、其他浏览器或未启用扩展的隐私窗口可能仍可用。扩展不读取网页正文。

扩展通常约五秒同步，结束或断联后在下次运行同步时解除。浏览器挂起时不能承诺固定解除时限。解除后刷新被阻止页面即可重新访问。

## 6. 紧急退出与异常中断

- 普通模式下，按 `Ctrl + Alt + Esc` 可立即结束本轮并解除应用限制。若快捷键注册失败，主界面会提示改用按钮。
- 普通模式下，点击“紧急退出”并确认后结束；全屏 Esc 或关闭请求也进入确认流程。
- 严格专注期间，上述应用内入口均被禁用，到时自动解除限制。休息不受严格选项约束，可以正常点击“结束休息”。系统层面的退出途径保留；不会拦截任务管理器或 Windows 安全桌面。
- 网站仍被阻止时，在扩展点击“解除限制并取消配对”，或在扩展管理页禁用扩展。取消配对后，后续网站限制需要重新配对。

普通模式的紧急退出保留实际专注时长，状态为“提前结束”，不计已完成番茄。普通与严格模式下，真正锁屏、休眠或注销会中断本轮并解除限制。自 0.7.4 起，单纯界面计时回调延迟超过五秒，不再自动结束或关闭全屏：这段停顿不计入时长，恢复响应后继续同一轮，严格状态保持。星球刷新遇到数据库繁忙时短暂等待后重试，不重新累计已保存的成长。异常退出后，下次启动只保留最后保存的时间，不补算停机期间，不扣已有星球成长。当前没有暂停后继续同一轮的功能，中断后可开始新一轮。

## 7. 专注热力图、统计与应用时长

“开始专注”页向下滚动可见年度热力图，每格对应当地日期的一天，悬停查看时长，左右箭头切换年份。它累计实际保存的专注时间，包含提前结束和中断，休息不计入；跨午夜、跨年分别归入对应日期。颜色由浅到深对应 0、少于 25、25–49、50–99、至少 100 分钟。

“专注统计”显示今日专注、所选年完成番茄、专注天数和最近记录；年份跟随主页热力图。完成番茄只计完成记录。“导出 CSV”可用 Excel 查看任务、时间、秒数与状态，最多导出最近 100,000 条；界面显示最近 12 条。

点击“应用时长”定位每日列表，可切换日期。“记录前台应用时长”默认开启，取消可暂停并记住选择。只要程序运行且统计开启，即使未开始番茄钟也会记录。

应用时长只计前台且最近 60 秒内有操作的应用；不补启动前历史、后台、休眠或未知间隔。浏览器按进程合并，不分网页。只保存进程名、日期和时长，不记录窗口标题、网址或输入。持续阅读或看视频而不操作超过 60 秒会暂停累计，因此可能与 Windows 屏幕时间不同。

## 8. Codex Token 立体日历

点击“Token 日历”或在专注主页向下滚动，查看所选年度、今日 Token、有记录天数及十二个月三维柱图。

启动时尝试读取本机 Codex 日志。默认沿用保存的目录，否则使用 `CODEX_HOME` 或用户目录下 `.codex`；找不到数据时，点击“选择 Codex 数据目录”，选包含 `sessions` 或 `archived_sessions` 的根目录。可以“刷新本机用量”，也可启用运行期间每两分钟刷新。首次读取较慢时可取消，后续跳过未变化文件；关闭后不再刷新。

日历左键拖动旋转、滚轮缩放，悬停查看某一天数值。双击或“重置视角”复位；“柱高”的平方根/线性只改变高度，不改变数据。`K`、`M`、`B` 分别表示千、百万、十亿，悬停汇总数字可看完整值。

**Token 是本机日志中可读取并去重后的估算，包含缓存输入，不是官方账单、账号余额、剩余额度或限额百分比。**其他设备、云端、删除记录、未落盘或不支持格式的事件可能不被覆盖。灰格表示没有可用本机记录，不表示实际使用为零。原始日志只读，仅缓存用量元数据，不保存或展示会话正文。

日历可以展示历史用量，星球只奖励启用后符合观察期的新用量，所以二者不必相等。首次绑定来源从星球启用时刻算起；以后更换来源或切回旧目录，从切换时刻开始新观察期，不把该目录的旧历史再兑换为成长。

## 9. 数据与备份

更新时只替换程序文件。先正常结束当前专注并关闭旧版，再运行新版；已保存的专注秒数和按日记录继续从原数据目录读取，不会重新累计。

从 0.6.1 起，首次使用一个新版本打开已有记录前，会自动生成 `backups/focus-before-<版本>-<时间>-<唯一编号>.db`。备份包含完整的 `focus.db`，使用 SQLite 在线备份方式纳入已提交的日志内容，并在独立重开后验证。成功才继续打开程序；失败时保留原库并停止启动。同版本重启不重复备份，旧备份不自动删除。

`focus-data-version.json` 记录已完成的版本备份。无需手动修改。若需要恢复，先关闭程序，保留当前整个数据目录副本，再选择所需的历史备份；不要在程序运行时直接覆盖数据库。

从旧版本首次升级到 0.7.0 时，`planet-layout.db` 还会单独生成 `backups/planet-layout-before-v1-<时间>-<唯一编号>.db`，再迁移到布局 schema 1。迁移逐行保留旧星球编号、物品 ID、类型、地块和朝向；备份失败、未知数据库版本或迁移错误时，不会用空布局替代。新建家园直接使用新格式，不生成不存在的旧布局备份。该布局备份与 `focus.db` 的升级备份是两份不同文件，仍建议退出程序后定期备份整个数据目录。

将 `%LOCALAPPDATA%\FocusGarden` 粘贴到文件资源管理器地址栏可打开数据目录。0.4 沿用该路径以兼容 0.3。

| 文件 | 用途 |
| --- | --- |
| `focus.db` | 原有专注记录、限制设置、按日累计和应用时长 |
| `codex-usage.db` | Token 用量缓存与去重索引 |
| `planet.db` | 多星球档案、周期、成长与防重复记录 |
| `planet-layout.db` | 每颗星球的地块布局和物品朝向 |
| `dashboard.json` | 记录开关及 Codex 数据目录等偏好 |
| `appearance.json`、`backgrounds` 文件夹 | 背景设置与图片副本 |
| `browser-pairing.key` | 浏览器配对码 |
| `browser-extension` 文件夹 | 点击按钮后导出的 8 个内置扩展文件，供浏览器手动加载 |

备份前结束专注并正常退出，再复制整个数据目录。恢复也应先退出，避免在写入时覆盖数据库。运行时可能有同名 `-wal`、`-shm` 辅助文件，不要只搬走其中一部分。

删除便携程序文件夹不会自动删除这些数据。数据只保存在本机，没有自动云同步；配对码不要公开发布。

## 10. 常见问题

**点数足够了，为什么没有解锁？**后续阶段还要求对应星龄，查看下一阶段开放日期。

**已经六个月了，为什么不能再次开拓？**每颗星球只能开拓一次下一颗。若尚未开拓，先结束当前专注或休息并完成 Token 刷新；若已开拓，在档案中前往新星球继续养成。

**内容不能放置或移动。**确认已解锁、未达到类型上限，且目标是空地块；生物还要满足手动合计 12 只上限。布局模式先选中已有内容，才能移动、旋转或收起。

**动物没有走向景观。**先取消布局模式，并确认场景可见。按搭配表把动物和适合的景观放近一些；并非所有相邻种类都会互动，陆地动物也不会为了目标强行跨过明显水面。

**编辑时动物突然回到原地。**这是为了便于准确选中保存的地块；观察动画没有改动它的存档位置。

**Token 日历全是灰色。**确认目录并刷新，查看读取错误提示。灰色不能用于判断账号额度，额度应在 Codex 自身查看。

**网站未拦截或结束后仍被阻止。**确认扩展启用、配对并同步，用新的页面导航测试。需要恢复时解除配对或禁用扩展。桌面提示本机连接服务不可用时，倒计时和应用限制仍可单独使用。

本说明提供操作方法和功能边界，不代表已完成真人桌面点击、真实浏览器拦截或每种显示环境的验收。已执行的验证与剩余检查请查阅交付的验收记录。


## 0.5 视觉与操作更新

星球主视图从 470 提升至 650 布局像素，相机默认让球体占据约 84% 的观景区域高度。使用右上角“展开观景”可最大化查看，使用“展开布置”可将星球与布局工具栏并排展开；Esc 或“返回主页”返回，专注计时继续运行。滚轮与 ＋ / − 均可缩放，布局模式不再自动缩小星球。

球面使用连续的海洋—浅海—沙滩—陆地色彩过渡与平滑光照。荒星加入陨石坑、层状岩、岩群和晶簇；成长后增加多种树木、灌木、野花、蘑菇、倒木生境、羊、兔、狐狸、鸭和鹿。小屋、风车、高塔、天文台补充门窗、台阶、格栅和观测设施细节。宇宙背景增加蓝紫星云与更多星辰。

沿用已有成长和布局数据库，32 个地块的坐标与编号保持不变；原有建筑位置不因美术升级移动。画面示例使用合成成熟星球，真实进度不被提升或重置。
