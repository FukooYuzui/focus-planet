从 v0.6.0 起直接记录后续开发提交。0.6 新增可切换的地表近景：上方星空、下方弧形地表，支持拖动环顾和独立远近调整。

0.7.4 修复五秒以上界面延迟误触发中断：跳过不确定间隔后继续同一轮，不关闭全屏或解除严格状态；附属星球数据库等待限制为约一秒，计时先于附属刷新。既有专注与成长记录保留，实际系统中断仍释放限制。

0.7.3 增加默认关闭、每轮确认的严格专注选项：本轮禁用应用内紧急按钮、Esc、全局紧急快捷键和窗口关闭；到期恢复，休息不受影响，系统与异常中断仍释放限制。设置沿用 JSON，不改变历史时长或数据格式。

0.7.2：改为自包含的 Windows x64 单 EXE，嵌入新的星球应用图标和浏览器扩展资源。无需另装 .NET；首次运行时内部提取所需原生运行库。扩展通过按钮导出到固定数据目录的 `browser-extension` 子目录，再由用户手动加载到浏览器。移动 EXE 不改变 `%LOCALAPPDATA%\FocusGarden` 中的存档；0.7.1 的模型及既有数据格式继续沿用。该版源码以 v0.7.2 标签归档。

0.7.1 精修近景生物、植物、池塘与山体模型，保留 0.7.0 的行为与布局格式，并继续执行几何预算和旧专注记录保护检查。

0.6.1 加入升级前专注数据库备份、较新数据版本保护、物理目录互斥及旧库逐条秒数不变的发布检查，保留 0.6 的地表近景。

0.7.0 将可布置内容扩展为 18 种，增加六种生物与六种景观、基于真实邻近景观的自动互动、编辑时动物归位与场景动画工作量控制。布局数据库首次从 schema 0 迁移到 1，迁移前单独备份，保留旧物品 ID、星球、地块及朝向；专注数据保护与地表近景继续保留。

`main` 指向最新版本。历史版本通过 GitHub 的标签选择器查看或下载，无需在最新源码中保留五份重复目录。后续修改继续形成新的提交，不覆盖旧标签。

归档保留源代码、测试源码、浏览器扩展、构建脚本和文档；排除构建产物、测试截图和报告、缓存、个人数据库、Codex 原始日志、浏览器配对密钥及用户背景图片。历史验收文档中与个人用量有关的数字已在归档副本泛化，原始本地快照保持原样。测试中的模拟数据和模拟凭证保留。

源码版本的功能及测试范围以该标签中的 README 和验收报告为准。归档操作没有重新运行全部历史版本的测试。

开发时使用 .NET 8 或更新版本 SDK。当前版本使用 WPF，仅支持 Windows 桌面。在 0.7.4 源码目录可执行：

```powershell
.\build.ps1 -Destination .\artifacts\FocusPlanet-0.7.4 -WorkDirectory "$env:TEMP\FocusGarden-build-0.7.4"
```

输出目录必须是新的或空的目录，中间产物写入指定工作目录。原有九组发布检查保留，新增 Timing 检查；通过后才继续生成单 EXE，并附带文档和备用扩展。历史标签中的构建方式仍以各自脚本和说明为准。
