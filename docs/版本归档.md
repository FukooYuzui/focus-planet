# 源码版本归档

本仓库于 2026-10-27 从五份已保存的源码快照建立版本历史。提交时间为归档时间，不代表原始开发时间；各标签对应当时保存的应用版本。

| 标签 | 应用名称 | 版本 |
|---|---|---|
| `v0.1.0` | FocusGarden | 0.1.0 |
| `v0.2.0` | FocusGarden | 0.2.0 |
| `v0.3.0` | FocusGarden | 0.3.0 |
| `v0.4.0` | 专注星球 | 0.4.0 |
| `v0.5.0` | 专注星球 | 0.5.0 |
| `v0.6.0` | 专注星球 | 0.6.0 |
| `v0.6.1` | 专注星球 | 0.6.1 |
| `v0.7.0` | 专注星球 | 0.7.0 |

从 v0.6.0 起直接记录后续开发提交。0.6 新增可切换的地表近景：上方星空、下方弧形地表，支持拖动环顾和独立远近调整。

0.6.1 加入升级前专注数据库备份、较新数据版本保护、物理目录互斥及旧库逐条秒数不变的发布检查，保留 0.6 的地表近景。

0.7.0 将可布置内容扩展为 18 种，增加六种生物与六种景观、基于真实邻近景观的自动互动、编辑时动物归位与场景动画工作量控制。布局数据库首次从 schema 0 迁移到 1，迁移前单独备份，保留旧物品 ID、星球、地块及朝向；专注数据保护与地表近景继续保留。

`main` 指向最新版本。历史版本通过 GitHub 的标签选择器查看或下载，无需在最新源码中保留五份重复目录。后续修改继续形成新的提交，不覆盖旧标签。

归档保留源代码、测试源码、浏览器扩展、构建脚本和文档；排除构建产物、测试截图和报告、缓存、个人数据库、Codex 原始日志、浏览器配对密钥及用户背景图片。历史验收文档中与个人用量有关的数字已在归档副本泛化，原始本地快照保持原样。测试中的模拟数据和模拟凭证保留。

源码版本的功能及测试范围以该标签中的 README 和验收报告为准。归档操作没有重新运行全部历史版本的测试。

开发时使用 .NET 8 或更新版本 SDK。进入所需版本目录后执行 `build.ps1`；当前版本使用 WPF，仅支持 Windows 桌面。
