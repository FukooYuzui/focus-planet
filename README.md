# 专注星球 · Focus Planet 0.8.1

一个从荒凉小星球开始、用专注与 Codex Token 助力养成的 Windows 桌面番茄钟。3D 卡通球面、宇宙星空、六个自然月养成周期，记录与家园布局只保存在本机。

## 0.8.1 取消每日成长上限

专注、Token 与共同助力都不再受每日上限限制。每满一分钟专注仍获得 1 点，Token 仍按对数递减换算，共同助力仍按两项贡献计算；当天累计超过原来的 120 / 60 / 20 点后可以继续增长，也不再有合计 200 点的上限。星龄要求和六个自然月的探索周期保留。

升级已有星球时，先备份成长数据库，再将已记录但被旧上限挡住的成长差额一次性补给升级时选中的星球，仍计在原来的日期。补发只依据星球成长记录中已保存的专注与 Token 观察值，不追溯启用星球以前的历史或尚未读取的日志；不会增加专注时长、重复导入 Token 或重复领取已经发过的奖励。具体升级保护与验证结果见交付说明和验收报告。

## 0.8.0 多应用白名单（历史更新，功能保留）

在“使用限制”中选择本轮允许使用的多个应用，再到“开始专注”页勾选“白名单专注”。开始前先打开至少一个允许应用的窗口；开始后通过浮动切换面板在已打开的白名单窗口之间切换。白名单模式使用工作窗口，不进入全屏沉浸。任务栏默认隐藏，常见的返回桌面和切换窗口快捷键默认被拦截；这两项可在开始前关闭。

本轮使用固定配置，白名单覆盖应用黑名单；允许浏览器后，已配置的网站限制仍继续生效。允许列表按进程名精确匹配，不能填写路径、通配符或窗口标题；不允许加入 Explorer、系统服务或通用窗口宿主。进程名规则不是系统权限隔离，改名程序、管理员窗口和特殊窗口仍有局限。

正常输入和应用内部操作继续可用。Ctrl + Alt + Del、Ctrl + Shift + Esc 和 Win + L 保留；严格专注只禁止应用内的提前结束。到时、正常结束或异常中断会恢复桌面，不强制结束其他进程，不修改系统长期配置。若白名单控制约八秒没有收到界面心跳，独立恢复进程会先恢复桌面，界面恢复响应后中断本轮；已保存时长保留，不补算停顿。崩溃后的记录恢复沿用下次启动流程。

下面各版本段落记录历史更新；当前白名单行为以上述说明及 `docs/使用说明.md` 为准。

## 0.7.5 减少卡顿（历史版本）

专注记录、应用时长、统计和星球成长的运行期数据库操作改为后台按序执行，界面不用等待数据库锁。专注仍按原频率保存，结束和关闭会等待已接受的保存任务；保存失败时明确提示，已保存秒数不重放。开始等待期间遇到锁屏或休眠，会取消本次开始；关闭保存失败时保持暂停，允许修复后再次关闭。

年度热力图复用格子，应用列表复用现有行；隐藏页面与全屏沉浸期间减少附属界面刷新，Token 立体日历首次显示时才构建。布置家园时只更新选区或变化物件，复用未变化的模型和网格，保留近景、精细模型、生物互动与原动画频率。CSV 导出在后台完成后替换目标文件，关闭程序会等待导出完成。

这一版不改变专注数据库结构与正常存档目录，不降低已保存的专注时间，也不通过提高动画帧率增加负担。实际验证范围和测量结果见验收报告。

## 0.7.4 修复界面延迟导致提前结束

修复普通和严格专注中，界面回调停顿超过五秒就自动中断并退出全屏的问题。现在保留同一轮专注、全屏与严格状态，跳过这段无法确定的间隔，恢复响应后继续倒计时，不补算停顿。真正锁屏、休眠、注销或专注记录写入错误仍按原规则释放限制并保留已保存时长。

计时保存先于附属统计和星球刷新执行；星球数据库忙时，单次等待缩短到约一秒，保留原成长记录，后续刷新重试，避免反复长时间阻塞界面。

## 0.7.3 可选严格专注

在“开始专注”页勾选“严格专注”，确认本轮时长后开始。计时期间，程序内的紧急退出按钮、Esc、Ctrl + Alt + Esc 和关闭窗口操作不能提前结束本轮；到时自动解除限制。开关默认关闭，旧设置保持普通模式，每轮严格专注都需重新确认。本轮开始后不能改设置解锁，休息仍可随时结束。

严格模式只限制本应用内的提前退出。任务管理器、系统锁定、休眠、注销和关机仍可用；系统中断或记录写入异常会解除限制，已保存时长保留，不补算停顿期间。它不承诺绝对无法退出，也不强制结束其他应用。

## 0.7.2 单文件程序与应用图标

现在可以只保留 `专注星球.exe`，双击运行，无需另装 .NET 或随身携带 DLL。新的星球应用图标、运行时和浏览器扩展文件均嵌入程序；同包文档和扩展文件夹可作为备用资料。首次运行该版本时，程序会将所需的原生运行库提取到 Windows 临时缓存，启动可能稍慢。

程序移动到其他文件夹后，仍使用 `%LOCALAPPDATA%\FocusGarden` 中的原有记录。网站限制需在“使用限制”页点击“打开扩展文件夹”，再按说明手动加载到 Edge/Chrome；该按钮将内置扩展导出到数据目录下固定的 `browser-extension` 文件夹，后续更新沿用这一位置。

## 0.7.1 近景模型精修

细化生物的五官、耳朵、翅膀、蹄爪与毛色，改善树冠、叶片、池塘和蘑菇的轮廓；山体增加不规则山脊、山脚与雪线。保留 18 种布置内容、原来的近景操作和生物互动方式，继续复用网格、控制总面数并在画面不可见时暂停动画。专注存档和家园地块沿用原位置。

## 0.7 生物与家园搭配

可布置内容增加到 **18 种**：保留树木、花丛、小屋、风车、观测塔、天文台；新增兔子、绵羊、狐狸、鸭子、鹿、蝴蝶，以及池塘、草地、蘑菇丛、果树、岩石庭园、灌木。初生星球就能布置岩石庭园，其他新增景观在 1 级解锁，六种生物在 2 级解锁。

在“布置我的家园”中按建筑、景观、生物选择条目，查看搭配建议，再点击“选择内容并放置”。例如把鸭子放在池塘附近、把蝴蝶放在花丛附近：退出布局模式后，动物会寻找附近实际存在、符合偏好的景观，进行短距离活动。没有适合的邻近目标时，不会凭空出现互动地点。它是自动的简单场景互动，不需要点击动物，也没有喂养、繁殖或生存系统。

进入编辑模式时，动物回到保存的地块位置并暂停活动，便于移动、旋转和收起；观察时的移动不改写布局。手动放置的生物每颗最多 12 只，另有最多 12 只随成长生成的自然生物。场景共用一个约 120 毫秒的动画计时器，页面不可见、画面离开可视区或窗口最小化时暂停场景动画；专注计时不因此暂停。以上是工作量控制，不是对任何设备帧率的保证。

旧 `planet-layout.db` 首次升级时先在线备份，再事务迁移到布局 schema 1，保留原有星球、物品 ID、地块及朝向；失败会停止迁移并保留旧布局。0.6.1 的专注记录保护和 0.6 的地表近景继续保留。

## 0.6.1 更新时保留专注时间

程序与记录分开保存，正常数据目录固定为 `%LOCALAPPDATA%\FocusGarden`。更新前正常结束专注并关闭旧版，再运行新版；不需要搬运或重新导入记录。

新版首次打开已有专注库前，会在同一数据目录的 `backups` 下创建并校验独立备份，包含已提交到临时日志的秒数。同版本再次启动不重复备份；备份失败、原库损坏或数据版本不兼容时停止启动，保留原文件。不会通过清空记录解决启动错误。

每次发布须通过旧库逐条秒数不变的升级测试；不把历史计时重新入账。自动备份不自动删除，备份/恢复前应关闭程序。

## 0.6 地表近景

在星球画面右上方点击 **地表近景**，从近处看弧形地平线：上方是星空，下方是局部地表，树木、生物与建筑会显著放大。拖动或使用方向键可以环顾其他区域，滚轮或 ＋ / − 调整远近；双击或 Home 重置当前视角。

点击 **全星球** 返回总览。两种模式分别记住当前运行期间的缩放，观察方向延续；近景关闭整球的自动转动，保留生物和云朵动画。也可点击“展开观景”或“展开布置”扩大画面，返回主页后继续使用同一视角。近景沿用真实成长与布局，不添加演示建筑或提前解锁内容。

## 开始使用

1. 将 Windows x64 版本的 `专注星球.exe` 保存到常用文件夹后双击。若下载的是压缩包，先解压出此 EXE；它可独立运行，无需另装 .NET 或安装开发工具。
2. 主页查看自己的星球；左侧“开始专注”进入番茄钟。可选择全屏沉浸或工作模式。
3. 新星球从零开始。旧专注记录和旧 Token 日历保留，不会在首次启动时直接变成成长。
4. 在“布置我的家园”的分类条目中选择已解锁内容，查看提示，点击“选择内容并放置”，再点击空地块；选中已有内容后可以移动、旋转 90° 或收起。每次操作自动保存。

如旧版还在运行，请先正常关闭。窗口标题和左下角应显示 0.8.1。本版继续使用 `%LOCALAPPDATA%\FocusGarden`，兼容以前的专注记录、背景和设置。移动或替换 EXE 不会搬走或清空数据；首次运行库提取所用的临时缓存与专注记录目录分开。工程内部仍保留兼容用的 FocusGarden 名称。

## 星球如何成长

- 专注每满一分钟获得 1 点，无每日上限；提前结束时已记录的时长也保留。
- Token 按对数递减换算，无每日上限；共同助力为“专注点数除以 3 后向下取整”与“Token 点数”中的较小值，也无额外每日封顶。
- 每日成长为三项之和，无合计上限。多个星球共享去重记录，不因切换或刷新重复奖励，新增成长分给当前星球。
- 150 点长出森林；1 个月且 1,200 点出现生物；2 个月且 3,000 点解锁家园；3 个月且 5,500 点解锁风车与塔；5 个月且 9,000 点进入星际绿洲。
- 满 **6 个自然月**可开拓下一颗星球，无需刷满点。旧星球、建筑和记录保留，可随时切回继续建设。每颗星球可开拓一次后继星球。
- 天气和昼夜会变化，动物微动、云朵缓移；不活跃、休息或中断不会扣成长。

Token 是本机日志中能读取和去重的估算，包含缓存输入，不是账单或账号额度。只有启用之后的记录参与成长；切换数据来源后按新的截止时间计算。切换星球前会先结算当前来源，失败时保留原星球。

## 3D 与布局

拖动旋转，滚轮缩放，双击或“重置视角”恢复；也可聚焦场景后使用方向键、Home 和加减键。采用 **32 个固定球面地块吸附**，18 种可布置内容共用这些地块，每块一个。动物既受单种上限约束，也受手动生物合计 12 只的上限约束；完整解锁表和搭配说明见 `docs/使用说明.md`。

不包含任意地形雕刻、道路编辑、战斗或联机。自动生长的自然景观与自然生物不能手动移动；你放置的生物、景观和建筑可反复调整，不消耗成长值。

## 原有功能

全屏倒计时、紧急退出、自选背景、当前时间、应用与网站新访问限制、SQLite 专注记录、年度专注热力图、每天前台应用时长，以及可旋转的 Codex Token 立体日历。统计和使用限制仍可从左侧进入。

普通模式的紧急快捷键为 `Ctrl + Alt + Esc`，全屏也保留紧急退出按钮；严格模式本轮禁用这些入口。不会禁用任务管理器、结束被限制进程或承诺绝对无法退出。网站限制需要手动加载由程序导出的 Edge/Chrome 扩展；更新程序后，再打开一次扩展文件夹并在浏览器中重新加载扩展。不保证关闭既有网页或已播放内容。

## 数据与源码

数据目录内包含 `focus.db`、`codex-usage.db`、`planet.db`、`planet-layout.db`、背景和设置。备份前正常退出程序，再复制整个数据目录。发行包和源码包不含个人数据库、Token 日志、浏览器配对码或用户图片。

源码使用 C# / .NET 8 WPF、SQLite 与原生 Viewport3D。只有编译源码时才需要安装 .NET 8 或更新 SDK。在源码目录执行下面的 PowerShell 命令，可生成自带运行时的 Windows x64 单文件版本：

```powershell
.\build.ps1 -Destination .\outputs\FocusPlanet-0.8.1 -WorkDirectory .\work\build
```

`Destination` 必须是新的或空的输出目录；脚本不会清理已有文件。`WorkDirectory` 存放构建中间文件，可改成其他工作目录。发布前依次运行十六组检查，任一失败即停止；生成单 EXE 后再附带文档和备用扩展。详细操作、数据边界和实际验证结果见 `docs/使用说明.md`、`docs/技术方案.md`、`docs/验收报告.md`。

## 0.5 视觉与操作更新

星球主视图从 470 提升至 650 布局像素，相机默认让球体占据约 84% 的观景区域高度。使用右上角“展开观景”可最大化查看，使用“展开布置”可将星球与布局工具栏并排展开；Esc 或“返回主页”返回，专注计时继续运行。滚轮与 ＋ / − 均可缩放，布局模式不再自动缩小星球。

球面使用连续的海洋—浅海—沙滩—陆地色彩过渡与平滑光照。荒星加入陨石坑、层状岩、岩群和晶簇；成长后增加多种树木、灌木、野花、蘑菇、倒木生境、羊、兔、狐狸、鸭和鹿。小屋、风车、高塔、天文台补充门窗、台阶、格栅和观测设施细节。宇宙背景增加蓝紫星云与更多星辰。

沿用已有成长和布局数据库，32 个地块的坐标与编号保持不变；原有建筑位置不因美术升级移动。画面示例使用合成成熟星球，真实进度不被提升或重置。
