# 专注星球 · Focus Planet 0.4

一个从荒凉小星球开始、用专注与 Codex Token 助力养成的 Windows 桌面番茄钟。3D 卡通球面、宇宙星空、六个自然月养成周期，记录与家园布局只保存在本机。

## 开始使用

1. 完整解压 Windows x64 压缩包，双击 `专注星球.exe`。程序自带 .NET 8 运行时，无需安装开发工具。
2. 主页查看自己的星球；左侧“开始专注”进入番茄钟。可选择全屏沉浸或工作模式。
3. 新星球从零开始。旧专注记录和旧 Token 日历保留，不会在首次启动时直接变成成长。
4. 已解锁物品可在“布置我的家园”中放置。开启布局、选择物品、点击空地块；选中已有物品后可以移动、旋转 90° 或收起。每次操作自动保存。

如旧版还在运行，请先正常关闭。窗口标题和左下角应显示 0.4。本版继续使用 `%LOCALAPPDATA%\FocusGarden`，兼容以前的专注记录、背景和设置。程序文件仍包含兼容用的 FocusGarden 名称；产品和启动程序已经改名为“专注星球”。

## 星球如何成长

- 专注每分钟 1 点，每日最多 120 点；提前结束时已记录的时长也保留。
- Token 按对数递减换算，每日最多 60 点；两者共同使用额外最多 20 点。
- 每日合计最多 200 点，多个星球共享当天上限，不因切换或刷新重复奖励。
- 150 点长出森林；1 个月且 1,200 点出现生物；2 个月且 3,000 点解锁家园；3 个月且 5,500 点解锁风车与塔；5 个月且 9,000 点进入星际绿洲。
- 满 **6 个自然月**可开拓下一颗星球，无需刷满点。旧星球、建筑和记录保留，可随时切回继续建设。每颗星球可开拓一次后继星球。
- 天气和昼夜会变化，动物微动、云朵缓移；不活跃、休息或中断不会扣成长。

Token 是本机日志中能读取和去重的估算，包含缓存输入，不是账单或账号额度。只有启用之后的记录参与成长；切换数据来源后按新的截止时间计算。切换星球前会先结算当前来源，失败时保留原星球。

## 3D 与布局

拖动旋转，滚轮缩放，双击或“重置视角”恢复；也可聚焦场景后使用方向键、Home 和加减键。第一版采用 **32 个固定球面地块吸附**，支持树木、花朵、小屋、风车、高塔、天文台；不包含任意地形雕刻、道路编辑、战斗或联机。自动生长的自然景观不能手动移动，已解锁的布置物品可反复调整，不消耗成长值。

## 原有功能

全屏倒计时、紧急退出、自选背景、当前时间、应用与网站新访问限制、SQLite 专注记录、年度专注热力图、每天前台应用时长，以及可旋转的 Codex Token 立体日历。统计和使用限制仍可从左侧进入。

紧急快捷键为 `Ctrl + Alt + Esc`；全屏也保留紧急退出按钮。不会禁用任务管理器、结束被限制进程或承诺绝对无法退出。网站限制需要加载随包提供的 Edge/Chrome 扩展；不保证关闭既有网页或已播放内容。

## 数据与源码

数据目录内包含 `focus.db`、`codex-usage.db`、`planet.db`、`planet-layout.db`、背景和设置。备份前正常退出程序，再复制整个数据目录。发行包和源码包不含个人数据库、Token 日志、浏览器配对码或用户图片。

源码使用 C# / .NET 8 WPF、SQLite 与原生 Viewport3D。安装 .NET 8 或更新 SDK 后执行 `build.ps1` 可生成自带运行时的 Windows x64 版本。详细操作、数据边界和验证结果见 `docs/使用说明.md`、`docs/技术方案.md`、`docs/验收报告.md`。
